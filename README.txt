نسخه وب مستقل دفترچه کدنویس

index.html را روی Cloudflare Pages، GitHub Pages یا هر میزبان استاتیک منتشر کنید.
داده‌های اولیه شامل ۸۲ رکورد بازبینی‌شده است. افزودن، ویرایش، حذف، جست‌وجو، تصویر و خروجی JSON در مرورگر کار می‌کند.
برای ماندگاری روی چند دستگاه، انتشار وب به‌تنهایی کافی نیست؛ یک میزبان ابری با پایگاه‌داده یا ورود/خروجی پشتیبان لازم است.
