۸۲ یادداشت اولیه از Code Android.docx حفظ شده‌اند. نمونه‌های نمایشی پیش‌نمایش‌ها وارد این نسخه نشده‌اند.
حوزه، پوشه و زیرپوشه، پروژه، برچسب، متن و کد، تصویر، نمایش برد/جدول/کارت، جست‌وجو، ویرایش، سطل بازیافت و بازیابی، خروجی و ورود JSON پشتیبانی می‌شوند.

ذخیرهٔ متن، کد و تصویر در مرورگر همین دستگاه است. همگام‌سازی خودکار بین دستگاه‌ها و حساب ورود در این نسخه وجود ندارد. از اطلاعات مهم مرتب خروجی JSON بگیرید و در محل دیگری نگه دارید.
کلید آرایهٔ یادداشت‌های نسخهٔ قبلی حفظ شده است؛ یادداشت‌های موجود همین مرورگر و همین آدرس بدون تغییر دستی قابل استفاده‌اند. داده‌های مرورگر یک آدرس دیگر یا دستگاه دیگر باید با پشتیبان JSON منتقل شوند.

انتشار: فایل‌های این پوشه را در ریشهٔ مخزن GitHub Pages قرار دهید. پوشهٔ source برای ویرایش محلی است و برای اجرای صفحه لازم نیست. برای استفادهٔ قابل انتقال، index.html را از همین بسته در مرورگر باز کنید.
پس از اولین بارگیری کامل نسخهٔ آنلاین، service worker فایل‌های برنامه را برای استفادهٔ آفلاین نگه می‌دارد. پاک‌کردن داده‌های مرورگر می‌تواند اطلاعات محلی را حذف کند؛ فایل پشتیبان مستقل نگه دارید.
